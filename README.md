# QA Portfolio — KITACTIVE

## О проекте

KITACTIVE — B2B HealthTech платформа для автоматизации учёта 
и обслуживания медицинского оборудования в медучреждениях 
(web + Android/iOS). 200+ клиентов по России.

Сайт продукта: https://kitactive.ru

Данный репозиторий содержит артефакты тестирования, 
созданные в ходе 17 месяцев работы единственным 
QA-инженером в команде.

## Что содержит репозиторий

### KITACTIVE.postman_collection.json
Коллекция API-запросов в Postman: авторизация, 
работа с заявками, проверка ролей и прав доступа, 
интеграционные запросы. Включает позитивные, негативные 
и граничные сценарии.

### Results - Test IT - KITACTIVE.xlsx
Результаты выполнения тест-кейсов в системе Test IT. 
Содержит статусы прохождения по модулям системы, 
приоритеты и типы тестирования.

### Load and security testing KITACTIVE.md
Чек-лист и сценарии нагрузочного и 
базового тестирования безопасности продукта.

## Стек и инструменты

Jira · Confluence · Postman · Test IT · 
SQL · Chrome DevTools · Fiddler · REST API · 
Android Studio · Agile/Scrum

## Что было сделано в проекте

- Выстроила контроль качества с нуля: 
  создала тестовую модель, 1000+ тест-кейсов и чек-листов
- Выделила критическую функциональность, 
  обеспечила критический регресс перед каждым релизом
- Тестировала 5 типов пользовательских ролей 
  и разграничение прав доступа
- API-тестирование (Postman): авторизация, заявки, 
  интеграции с Аршин, модуль телеметрии (IoT)
- Сопроводила 70+ еженедельных релизов 
  без критических дефектов на продакшене
- Поддерживала и актуализировала тестовую модель 
  на протяжении 17 месяцев
