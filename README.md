# QA Portfolio — KITACTIVE Testing Project

## О проекте
Данный репозиторий содержит выполненное тестовое задание для веб-приложения KITACTIVE.

Целью работы было провести полноценное ручное тестирование продукта и продемонстрировать навыки QA-инженера: анализ требований, поиск дефектов, оформление тестовой документации и работа с тестовыми сценариями.

## Что было сделано

- Проведено функциональное тестирование веб-приложения
- Выполнено исследовательское (exploratory) тестирование
- Найдены и описаны баги
- Составлены тест-кейсы и чек-листы
- Проведен анализ пользовательских сценариев
- Проверена логика работы ключевых функций системы

## Использованные инструменты

- Browser DevTools (Chrome)
- Postman (базовая проверка API)
- Jira (логика оформления баг-репортов)
- GitHub (документация и хранение результатов)

## Навыки, продемонстрированные в проекте

- Написание тест-кейсов и чек-листов
- Оформление баг-репортов (steps, expected/actual result)
- Анализ UI/UX и пользовательских сценариев
- Работа с HTTP-запросами и ответами
- Базовая проверка API
- Внимание к деталям и поиск edge-case сценариев

## Структура репозитория

- Test Cases — тест-кейсы
- Checklists — чек-листы
- Bug Reports — найденные дефекты
- Additional Notes — дополнительные наблюдения и выводы
